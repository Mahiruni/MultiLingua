# MultiLingua

Mobile-first nine-language educational prototype. Supports 72 directional language combinations, swap, ten illustrative vocabulary items, timed multiple-choice tests, local progress, dictionary search, browser TTS where available, and a profile stored locally.

## Run
Open index.html or serve with a static file server. No build step.

## Status
This is a functional prototype, not a production-ready application. Vocabulary translations require independent native-speaker review. No Supabase authentication, cloud sync, full curriculum, image library, AI speech recognition, subscriptions, payments, native APK, or deployment has been implemented. TTS availability depends on installed browser voices.

## Next
